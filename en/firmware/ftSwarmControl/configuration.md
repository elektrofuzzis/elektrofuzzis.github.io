The ftSwarmControl can control up to 4 different models at the same time. However, to operate an excavator and a wheel loader with one remote, the controls alone are not enough. For both models, for example, the left joystick should control the drive and the right joystick the steering. So you need to switch back and forth between the two models.

![Home](/assets/img/ftSwarmControl/active-config-en.png){:.align-center style="width: 25%;"}

The controller can store up to 4 different configurations for control. For example, configuration #1 can be used for the excavator and configuration #2 for the wheel loader.

In this menu item, you can now switch seamlessly between the 4 different configurations. The actual functionality — which joystick or button controls which actuator — is defined in the Remote/Event configuration of the classic firmware or via the remote control menus of ftSwarmControl.

Switching between configurations can also be useful for complex models. A truck crane has two operating modes — driving like a car and the crane function. Both cannot be used simultaneously. Thus, for example, driving can be assigned to Configuration #1 — left joystick for propulsion, right joystick for steering. In Configuration #2, raising and lowering the crane hook can be controlled via the left joystick, and rotating the crane can be controlled via the right joystick.
