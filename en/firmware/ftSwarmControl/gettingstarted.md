With the ftSwarmControl, configuration can also be performed directly on the controller.

![Home](/assets/img/ftSwarmControl/main.png){:.align-center style="width: 25%;"}

The configuration mode is started from the ftSwarmControl status screen using the **SET** button or S4.

![Home](/assets/img/ftSwarmControl/config-en.png){:.align-center style="width: 25%;"}

You can now use the ftSwarmControl controls to navigate the menus:
- Use the left joystick to navigate the screen.
- Press the joystick (Button J1) to select a highlighted option.
- The F2 button is the “Escape” key and exits the current menu. This function is indicated by the ^ symbol in the upper-right corner.
- When buttons S1 through S4 are used, their functions are displayed at the bottom of the screen.

![Home](/assets/img/ftSwarmControl/ftSwarmControl.svg){:.align-center style="width: 25%;"}

As long as you are in the configuration menus, model control via joysticks and buttons is, of course, disabled.
