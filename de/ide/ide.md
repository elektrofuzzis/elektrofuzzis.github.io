Für die Programmierung der ftSwarm-Controller in c++ gibt es die beiden Möglichkeiten Arduino und PlatformIO.

[Arduino](../arduino)
ist die verbreiteste IDE für DIY Projekte. 2005 wurde sie in einem Projekt zur Entwicklung eines Open-Source-Mikrocontroller-Boards entwickelt, heute unterstützt die Platform alle gängigen Mikrocontroller. 

[PlatformIO](../PlatformIO)
ist ein Plugin für Standard IDEs wie [Visual Studio Code](https://code.visualstudio.com/) zur Entwicklung von Embedded Systems. Das Einrichten von PlatformIO ist etwas komplizierter, die IDEs sind jedoch deutlich besser und das Compilieren der Software deutlich schneller.
